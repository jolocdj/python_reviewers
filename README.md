# 🐍 Python Basics Reviewer 

A simple and beginner-friendly collection of Python concepts, examples, and practice snippets. This repository is designed to help reinforce fundamental Python knowledge for students and self-learners.

--- 

## 📌 Contents 

* ✅ Variables & Data Types
* ✅ Input & Output
* ✅ Operators
* ✅ Conditional Statements (`if`, `elif`, `else`)
* ✅ Loops (`for`, `while`)
* ✅ Functions
* ✅ Lists, Tuples, Sets, Dictionaries
* ✅ String Manipulation
* ✅ Basic Error Handling 
* ✅ Simple Practice Exercises

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jolocdj/python_reviewers.git
```

### 2. Navigate into the project folder

```bash
cd python_reviewers
```

### 3. Run Python files

```bash
python filename.py
```

## 📝 Sample Topics

### Variables

```python
name = "Jolo"
age = 20
```

### Conditional Example

```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

### Loop Example

```python
for i in range(5):
    print(i)
```
